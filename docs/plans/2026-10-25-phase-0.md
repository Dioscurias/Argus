# ARGUS Phase 0 implementation plan

**Goal:** Deliver the requested runnable foundation, then stop before Phase 1.

**Architecture:** Vite/React/TypeScript client and a small Express server share a typed entity and streaming contract. The server owns provider configuration, deterministic mock generation, a short-lived cache, and WebSocket snapshots. MapLibre renders bundled Natural Earth geography; a deck.gl overlay provides the future entity-rendering integration point.

**Tech stack:** React, TypeScript, Vite, Blueprint dark UI, MapLibre GL, deck.gl, Express, ws, Node test runner, Playwright browser verification.

## Design and scope

The user's supplied specification is the approved design. Implement its exact colors, typography, square controls, and dense analytical layout. Use an empty operational map in this phase: mock entities stream to the client, but transport markers begin in Phases 1–3. Keep upcoming controls visibly unavailable, with their phase stated. No live source connections, search, selection, replay, or analytical filtering in Phase 0.

Use locally bundled geography and fonts. The map must survive an unavailable provider server. Visibility, opacity, isolate, drag/keyboard reorder, projection, zoom, and reset are working foundation controls. Layers without implemented data expose clear pending states. Feed counts are labeled buffered, separate from rendered counts.

## Implementation sequence

1. Create package scripts, strict TypeScript configuration, Vite API/WebSocket proxy, environment template, and documentation.
2. Write behavioral tests for deterministic modeled entities, movement and coordinate validity, cache expiry, layer isolation and reorder, server configuration validation, and HTTP/WebSocket agreement. Confirm missing features fail.
3. Implement `shared/schema.ts`, provider interface/mock provider, server cache/config/app, and WebSocket lifecycle with cleanup, heartbeat, bounded backpressure, and same-origin validation.
4. Implement modular layer descriptors and layer reducer; bundled geography, graticule and computed night mask; MapLibre with an empty deck.gl overlay.
5. Implement the Blueprint app shell, layer panel, feed hook with reconnection/stale states, pending inspector, UTC clock, and honest status bar.
6. Install dependencies, run type checks/unit/integration tests, build production assets, and verify the UI in Chromium at desktop and narrow widths. Exercise controls, socket disconnect/recovery, and projection changes.
7. Deliver complete files in the workspace plus a source archive, setup instructions, scope notes, and verification evidence. Stop and wait for “continue.”

## Verification

- `npm test`: deterministic, valid and MODELED-only mock entities; movement; cache lifetime; layer isolation/reorder; configuration validation; HTTP and streaming integration.
- `npm run build`: client and server TypeScript plus production Vite build.
- `npm run test:browser`: app loads without external runtime requests, map/projection works, layers toggle/isolate/reorder/adjust opacity, reconnect behavior, responsive layout, no browser exceptions.

No performance claim for the eventual 70,000-entity target is made in this phase.
